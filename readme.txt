Point of Sale for WooCommerce.

== Description ==

Pika POS adds a counter till to a WooCommerce shop, so in-person sales become
ordinary WooCommerce orders — stock moves, reports add up, refunds work, and
every other WooCommerce extension keeps behaving as it should.

This is an early skeleton. Nothing is implemented yet.

== Installation ==

1. Upload the plugin to `wp-content/plugins/pika-pos`.
2. Run `composer install && npm install && npm run build` in the plugin folder.
3. Activate the plugin through the Plugins screen.
